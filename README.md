# imgui-toolkit
A modern C++ toolkit built on Dear ImGui to simplify GUIs.

This project was originally created to support development of [Olympian Game Engine](https://github.com/RyanDeBarros/Olympian/).

## Licensing

All third-party licenses can be found in the `licenses/` folder. The following libraries are used:

- **ocornut/imgui**
- **aiekick/ImGuiFileDialog**
- **nigels-com/glew**
- **GLFW**
- **nothings/stb**
- **memononen/nanosvg**
